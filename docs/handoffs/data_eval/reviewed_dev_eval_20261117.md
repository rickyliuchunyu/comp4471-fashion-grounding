4. 验证建议保留当前dev主集，再独立增加约50–100张困难图片作为**补充挑战集**，从未分配的官方validation图片组选择、先去重和人工核验，再冻结。困难集单列结果，不与主集直接混算后声称自然分布泛化率；不从test抽图。
5. lcy的10k分割扩充已经交付，5k/10k受控对照正在运行。先看该对照结果，再决定是否继续增加分割数据。现有证据提示鞋/小配饰及错类问题，不能据此证明再加普通分割图必然有效。
