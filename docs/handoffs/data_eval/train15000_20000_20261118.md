## 可行性、采样与缺口

官方train共45623图。排除原10k和规则不符后，34699图通过源RLE元数据检查；排除922张jumpsuit图、1张无整件图、1张无效mask图。**34699不是全部已下载去重的数量。**
实际采集16990张，1434份已有文件/指纹复用，15556份走可恢复ZIP范围读取及CRC检查。图像检查失败0；隔离817候选：544与旧/保护组件相连、235新组多余代表、38已属保护关联组。得到16173个独立组，选10000，余6173；其他官方余量尚未下载去重。

seed=2026，先固定广泛采集池，再补稀缺目标候选；不是纯随机规模消融。每阶段配置2500广泛位+2500优先位，按广泛覆盖后剩余缺口比例选择。无可用缺口命中后按固定顺序补广泛样本，**不把所有优先位声称为稀缺难例**：

- 第一阶段：2500初始广泛、814次缺口优先、1686广泛回填。
- 第二阶段：2500初始广泛、1094次缺口优先、1406广泛回填。

sidecar的`sampling`表示槽位；`selection_mode`明确上述实际决策，RELEASE同时登记实际数量。

按新增独立图片计，一图可命中多项。small为原图源mask面积≤1024，extreme≤256；相对面积与八类/26源细类统计见[完整分布](train15000_20000_20261118_evidence/distribution_report.json)。

## 验证与限制

- 旧10k指定manifest/annotations/SHA256SUMS/mapping pins匹配；合并包逐项保留旧manifest、COCO image/annotation、GT候选及source_subset记录。复制目标资产对旧摘要检查，**未重新解码旧10k像素/mask**。
- dev250 manifest/annotation、test400 manifest指定pins一致；test只读取保护manifest及已存指纹/组，没有打开test图像、mask、查询或模型成绩。全部50张dev曝光图（39入选+11隔离）及关联组受到保护，发布前重新核对。
- 仅新增—旧、新增—保护、新增—新增的SHA/资源URL/group与原/镜像四组合63bit pHash≤6检查；独立复查新增10000张，保留冲突0。不是穷尽所有裁剪/同商品关系的证明。
- 第一/第二增量19260/18989个mask逐像素与官方源一致；新增RGB读取、hash、尺寸、RLE非空、area、bbox、候选、schema检查通过。旧检查按固定hash复用。
- 5项针对镜像冲突/连通桥接/每组代表/面积阈值/父级身份的CPU检查通过，未重跑历史全套或模型测试。
- 新增视觉抽查seed=2026+phase，实际AI观察36个目标、36张图；非人工、非全量质量认证。[逐条观察](train15000_20000_20261118_evidence/visual_audit.json)保留不确定项。旧八类图示复用父包audit/class_preview，未重看旧10k。
- **源质量疑点**：image20340/source annotation25910的镂空上衣，肩部开口保留，但部分袖部开口/袖口邻近手部区域被连片覆盖。保持官方mask、列为待人工质量复核，不称为精确孔洞监督；补充图`audit/visual_preview/detail_ann25910.jpg`。极小目标中还存在分辨率不足以独立认证语义/边界的情况。
- **旧分区关联线索**：2个保守组件连到实际旧10k与固定dev/test或dev曝光图，相关新候选全部隔离，旧分区不动。其余5个跨官方train/val组件涉及历史关联val成员。仅为未视觉确认的线索，不认定为已确认泄漏。[桥接审计](train15000_20000_20261118_evidence/bridge_audit.json)单列待独立数据审计处理，不用test表现调模型或选样本。
