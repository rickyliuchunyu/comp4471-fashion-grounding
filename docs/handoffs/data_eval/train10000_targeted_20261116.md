## 去重与源保真

6500 张下载/复用候选已解码检查，126 张被保守隔离，剩余 6374 张/组可用，其中选取 5000 张。候选池统计 `audit/eligible_pool_report.json` 的范围仅为本次已下载并去重的池，不宣称整个官方剩余集都已完成图像去重。
检查包括 SHA256、有效资源级 URL，以及原图/镜像全部四种 pHash 组合（63-bit，Hamming ≤6）的连通分量。任何新候选所在分量触及固定 train/dev/test 则隔离；其余新分量只留一个代表。pHash 是保守冲突线索，不冒充人工确认的同商品身份，不保证检出所有裁剪或同人物相似图。
独立复查新增-原划分、新增-新增组合，剩余冲突为 0；不改写冻结记录的 group_id。隔离原因与关联 ID 在 `audit/duplicate_audit.json`。
此前未发布临时选择因补充镜像方向检查发现额外线索而废弃；初始 staging 和日志保留，最终发布只使用本次 mirror4 运行。
