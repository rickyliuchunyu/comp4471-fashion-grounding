# 50k 候选上的 M2 方位加分实验

2026-11-18，wkq（data_eval）在 AutoDL 的独立 CPU 环境复核了 wyz 的 50k 结果，并在冻结的 clean1000 M2 上尝试推理时加分。当前建议保留此版本，作为后续盲测的对照方法。

## 方法与输入

保留 M2 对每个候选的分数。共享解析器能唯一识别类别和左、右、上、下方向，且不含未支持的操作时，在同类候选内部按框中心位置排名，复用 B2 已选的权重 2 加分。只有一个同类候选时加分为零。正式 dev 直接从同一批候选的 B2 和 B1 冻结分数之差还原这项加分，再对 M2 重新取最高分。查询类型和目标 ID 只在选完后用于统计。权重 2 原先由 wyz 在这批 dev 的 GT 候选上选出，此次沿用。

参考实现为 grounding 提交 `b5e372925dcd6f581fb1a0c8f65bd5dee5dde3cd`。种子 42，两份训练集各跑 490 次更新，使用原实验选中的检查点。M2-clean1000 的 SHA-256 为 `3a28bfe0dad397b68595c70aafa2ef4a123d835d159ddae3948d51503902f7c8`。本次只运行推理和评价。[wyz 的训练与候选交接](https://github.com/rickyliuchunyu/comp4471-fashion-grounding/pull/5)

## 已审核 dev，端到端

50k 指分割检查点的 50,000 次更新。分割包有 250 图和 1,279 个候选，642 条已审核中英查询覆盖其中 246 图、321 组语义。严格选对使用统一评价器的同类实例一对一匹配，掩码达标按目标 mask IoU ≥ 0.5 计算。

| 方法 | 严格选对 | 掩码达标 | 外观严格选对 | 外观加方位严格选对 | 纯方位严格选对 |
|---|---:|---:|---:|---:|---:|
| B2 | 490/642 | 531/642 | 462/606 | 21/26 | 7/10 |
| M1，1000 图 | 499/642 | 548/642 | 482/606 | 14/26 | 3/10 |
| M2，1000 图 | 503/642 | 554/642 | 485/606 | 15/26 | 3/10 |
| M2，1149 图 | 503/642 | 551/642 | 485/606 | 15/26 | 3/10 |
| M2，1000 图，加方位分 | **512/642** | **563/642** | **485/606** | **21/26** | **6/10** |

相对原 M2，两项总体指标各提升 1.40 个百分点。24 条得到非零的方位分，13 条换了首选候选，只涉及 6 图。按严格选对计，10 条改对、1 条改错、2 条仍错。改对的 10 条中有 9 条是鞋，另 1 条是包。纯方位 10 条来自 3 图。按图片配对重采样 10,000 次（种子 2026），两项差值的描述性 95% 百分位区间均为 +0.34 至 +2.67 个百分点。区间仅描述本次 dev，在看过开发结果后提出的方法需要另行验证。

“画面右边的黑色鞋”（图 1000019769）由 IoU 0 升到 0.934。图 1000017972 的英文右鞋查询则从正确候选 065 切到 004，IoU 从 0.612 降到 0.290。图上有两个鞋实例、四个鞋候选。065 和 004 的框分别是 [579,503,668,644] 和 [590,504,668,643]，后者中心略靠右。这个例子说明同一位置附近的重叠候选也会被规则排出先后。

## 分工与复现

- wkq 可优先从训练划分选取同图、同类、不同位置的两个物体，为两个目标分别写相反方向的查询，增加鞋以外的类别；记录独立图片数和中英配对数。clean1000 的纯方位为 42/2998 条，expanded1149 为 106/3296 条，两次 M2 在正式 dev 的纯方位均为 3/10。
- wyz 可先冻结本次规则做对照，再单独验证同类重叠候选是否应共享方位加分，把最终选择交回外观排序。建议同时记录纠错和退步例，保持最终 test 封存。
- 服务器运行根目录为 `/root/autodl-tmp/fashion-grounding/runs/data_eval/20261118-spatial-residual-v1`。其中 `reviewed/evaluation.json` 和 `reviewed/predictions.jsonl` 来自统一评价，`draft/draft_diagnostic.json` 是逐条草稿诊断。`comparison.json` 记录配对差异。下列命令从 wkq 的 data_eval 工作区执行，复跑时选用新输出目录。

```bash
B=/root/autodl-tmp/fashion-grounding
R=$B/runs/data_eval/20261118-spatial-residual-v1
CFG=$R/grounding-src/configs/grounding_u50000_dev_20261118.json
REF=$B/runs/grounding/u50000-reviewed-dev-20261118-r01

  --config "$CFG" --reference "$REF" --output "$R/replay/reviewed"
HF_HUB_OFFLINE=1 CUDA_VISIBLE_DEVICES="" PYTHONPATH="$R/grounding-src/src" \
  "$R/env/bin/python" scripts/probe_draft_spatial_prior.py --config "$CFG" \
  --pack-dir "$B/shared/processed/fp_language_dev39_challenge_draft_v1" --output "$R/replay/draft"
```
