## 采样与规模

- 范围仅 Fashionpedia 官方 train，保持既有八类整件映射、排除部件与含 jumpsuit 图的规则。不混入 DeepFashion2，不改变类别头。
- 目标为旧 5k + 约 5k 新图片。旧子集原 image/annotation/source ID、原 mask/框、来源字段保持不变；旧包不覆盖。旧文件记录不因重新打包而静默改标签。
- 推荐新增约 3,500 张广泛采样 + 1,500 张定向补缺。按固定 seed（沿用 2026）和已有图组处理，先记录广泛采样所得覆盖，再用补缺部分填缺口；不把近重复当新增独立样本。图组约束优先于整齐的整数配额，达不到 10k 应报告实际数量，不跨组拆分凑数。
- 给每张新增图记录 `broad` 或 `targeted` 采样来源和目标细类/尺寸原因；单独的 sidecar 即可，无须破坏现有 schema。下面各目标可在同一张图同时满足，图片总数和每项命中分别去重。
- 这是“定向扩充”需求，不是纯数据量消融。若之后需要纯数量对照，应另固定同分布采样规则；本轮不要求多构建一套对照包。
