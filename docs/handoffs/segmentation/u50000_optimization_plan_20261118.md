## 第一项：只改变训练图像的抽取分布

按已验收train10000原标注生成版本化采样索引，不复制图片或改数据包。候选弱组为含原图mask面积≤1024的小袜、腰带、小鞋、头饰或手表的图像；源细类仅用于训练采样，模型仍输出原八类。不能按dev失败图ID、语言目标或测试信息选图。

B组7500次图像曝光来自原均匀流，2500次来自弱组流，合计10000次。弱组流在五个组之间轮转，组内按固定种子打乱；每组图像ID去重，共享图像存为一个条目，可以按重采样设计再次曝光，但记录真实每图/每组次数，不能算作新增数据。先从metadata确定非空组及集中度；空组显式报错，不静默改配方。需检查是否被少数多组命中图像主导，若需改配额，训练前同时固定方案与hash。

每次取图保留所有八类GT，仍走原768、LSJ0.5–2及水平翻转增强，不新增目标中心裁剪或只留下目标标注。已有裁剪损伤同图其他实例的诊断复用。

| 项目 | A：同预算参照 | B：唯一实验改动 |
| --- | --- | --- |
| 初始化 | 同一50k，仅加载模型参数 | 完全相同 |
| 数据 | 原train10000，均匀打乱 | 相同10k，75%均匀＋25%弱组 |
| 优化器等状态 | 新优化器/调度/采样/RNG，seed42 | 相同重置规则，采样器使用独立RNG |
| 微调配方（拟） | LR2e-5、backbone×0.1；250步warmup后cosine，min_factor0.02 | 相同 |
| batch与预算 | 有效batch2，新增5000成功updates | 完全相同 |
| 模型、mask损失、匹配、增强 | 保持当前实现 | 完全相同 |
| 评价 | 末端一次完整dev250；原800/1333、FP32、top100、无score阈值AP | 同一协议 |

5000updates是10000次曝光，即1等效epoch；B不等于每图恰好遍历一次。LR是成熟权重短微调的预设，不声称已验证最优，不在本轮搜索。旧50k是部署参照，不能代替等量新增训练的A，否则无法分辨“多训练”与“采样改变”的贡献。

按既有10000updates＋dev约72–75分钟，粗估每组约37–40分钟；拟每组总硬上限60分钟、两组120分钟，包含训练、末端评价和选择。若后续单独导出胜出者候选，须明确纳入实际执行总预算；不默认追加。失败/超时即停，不自动续跑或延长，不把未完成组当作同预算结果。本轮没有检查服务器实时资源或启动；执行前再检查整组GitHub、磁盘、GPU及共享锁。

## 判断有效与发布条件

执行前固定以下工程筛选规则，所有AP变化以百分点计：

1. 采样实验有效：B整体AP≥A，AP75≥A，且AP_small相对A至少+1.0，或shoe/bag/accessory三类等权平均AP至少+0.5。两条针对性条件分别报告，弱类通过不能写成小目标也已解决。
2. 权重选择：比较已有50k、A、B，保持完整dev整体AP优先；同分保留原版本。B通过采样门槛但未超过旧50k整体AP时，不替换交付。若A更好，只能说明短续训有效，不能宣称重采样获益。
3. 边界/弱细类分别看：AP75、固定小目标集合的高IoU匹配、袜/腰带/头饰/手表匹配变化，以及像素precision/recall。共同匹配的GT用于配对边界比较，所有138个小目标保留检测分母，避免删除困难样本后“平均边界变好”。小包仅2例不单独调参，全部45个包作监控。
4. AP解码与候选解码保持分开。第一阶段只使用新权重末端AP推理保存的结果作同协议比较，旧50k AP预测直接复用；不把AP top100计数与原0.3候选计数混比。只有胜出者拟交付时才做必要的新候选导出，固定0.3，复用离线诊断入口检查原138个小目标和200个配饰，特别看漏检、外溢及89个背景/未标注区域预测是否恶化。不能通过重新搜索阈值掩盖模型退化。
5. 以上门槛是单seed、有限dev的开发决策，不是显著性或test结论。微小改善不值得反复调整配额追dev分数；保留现有50k可用版本。

## 第二项：有针对性地改善边界监督

只在第一项结论明确后考虑。官方[criterion](https://github.com/facebookresearch/Mask2Former/blob/main/mask2former/modeling/criterion.py)对匹配mask采样不确定点及随机点，计算sigmoid BCE与Dice。当前没有训练时逐实例点命中证据，不能先断言“小目标没被监督”。

若实施下一次有授权的A/B，可在其已有训练前向中轻量记录小目标前景/边界点命中率、分类概率与mask质量，频率和数量提前限额；不为日志另跑模型。检查新增记录不会改变采样RNG或loss。若训练点确实少覆盖小目标或细边界，再单独准备保底点采样：总12544点不增加，拟80%原策略、10%GT前景、10%GT边界内外邻域，保留背景负点，空集合回退原策略。

这是新的监督分布实验，不是修复已证实的bug；保持分类、Hungarian匹配、损失权重、训练尺度及已选图像采样配方固定。A/B仍同起点、同新增预算，不和图像重采样同时首次引入。监督命中已充分时，不自动实施该机制，应根据新增训练记录再决定表示/尺度问题是否值得另立实验。
