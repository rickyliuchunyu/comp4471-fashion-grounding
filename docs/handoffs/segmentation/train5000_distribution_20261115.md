## 复用与统计口径

输入为现有 `fp_train5000_v1`。只核对本次实际读取的 annotation/manifest/mapping 文件身份；三份 SHA256 与 [已验收输入](large_input_acceptance_20261112.md) 相同。原始 mask 面积、图像尺寸、八类映射和几何合法性均复用既有检查，不再读取图像、逐 mask 解码或执行完整 loader。

- 5,000 图、4,976 个已有近重复组、17,775 实例；没有 crowd/ignore 被排除。组计数不是已验证的不同人物/商品数。
- 小目标按原图 mask 面积 `0 < area <= 1024`；极小目标 `area <= 256` 是其子集。分箱 `<=64 / (64,256] / (256,1024] / (1024,9216] / >9216` 互斥，总和等于实例数；这是描述统计，不重新计算 COCO AP。
- “含该类图数”“含小目标图数”各自在行内去重；不同类别可出现在同图，行间不可直接相加当图片总数。
- 同时导出 mask 占原图面积 <=1% 的计数，避免仅凭绝对面积解释所有尺寸问题；它不是 COCO-small。所有统计都是增强前分布，不证明 LSJ 后的实际目标曝光。
- 所有 26 个保留源细类均列入 CSV；不存在的细类应计 0，空分位数为 null。源细类仍属于现有八类，不另建分类头。
- 本轮没有读取语言查询、test 标注或测试图片。dev 结论只引用已保存报告/小目标汇总，不重做评价或匹配。

小目标占 **12.18%**，极小目标占 **3.04%**；鞋+配饰占全部小目标 **95.43%**。dev 小目标为 138/1008=13.69%，整体小目标占比没有表现出数量级差异；这不能证明细类、场景或增强后分布一致。

鞋占训练实例的 28.35%，数量最多，却仍低于多数整件衣物的 AP。因此不能把鞋的错误主要归为总实例数不足。相反，bag 总体只有 780 图、其中小包仅 28 图，增加不同场景的真实包实例更有数据覆盖依据。skirt 总数少于 bag 却有更高 AP，也说明“数量越少一定越差”不成立。train 没有绝对面积小裙，dev 也仅 1 个，记录覆盖空白，但不围绕这一例设置高额采集目标。

## 弱细类与已有错误联合判断

| 源细类 | train 实例 / 图 | train 小目标 / 含小目标图 | train 极小目标 | dev 小目标 IoU>=0.5 / >=0.75（18k，复用） |
| --- | ---: | ---: | ---: | --- |
| sock | 263 / 149 | 185 / 115 | 111 | 4/13；2/13 |
| belt | 722 / 710 | 146 / 141 | 27 | 5/11；1/11 |
| headband, head covering, hair accessory | 395 / 329 | 225 / 172 | 116 | 10/14；4/14 |
| glasses | 512 / 512 | 132 / 132 | 27 | 6/8；2/8 |
| shoe | 5,040 / 2,611 | 991 / 777 | 157 | 54/68；16/68 |
| bag, wallet | 811 / 780 | 28 / 28 | 1 | 2/2；1/2 |
| watch（对照） | 404 / 402 | 296 / 296 | 79 | 17/18；10/18 |

1. **袜子优先补不同图/组。** 263 个实例来自 149 图，42.21% 为极小目标；已有 dev 召回也弱，兼具数据覆盖和尺寸难度信号。
2. **腰带、发饰和眼镜补细形状及小尺寸覆盖。** 腰带不是总量最少，但小腰带仅 141 图且严格匹配差；发饰、眼镜也需检查可见形状多样性。计数本身不证明边界标注好坏。
3. **鞋优先补困难形状多样性，同时验证细节保留。** 复用的凉鞋外溢/孔洞案例支持这一方向；不能把 991 个小鞋全部视为独立场景，也不能仅靠随机增加普通鞋保证边界收益。
4. **包补总体覆盖，小包设置可行的软目标。** dev 小包只有 2 例，不能依据这个子组 AP 宣称显著收益或反复选样调参。
5. **保留非优先类的覆盖。** cape 13 实例/13 图、leg warmer 12/7、umbrella 17/17 是长尾；当前没有足够 dev 小目标证据把它们列为首轮主要瓶颈。新增时自然保留，不为凑齐八类而改映射或补造标签。手表较好也不代表所有配饰都已解决。

上述分析是相关性与覆盖描述，不是数据扩充的因果收益，也不证明模型已达到当前数据上限。

## 下一步与停止边界

- **当前优化执行顺序仍先保留 min_scale 单因素短对照，再按实际结果决定后续。** 18k 后学习率很低，因此该短对照阴性不能排除更充分适应时的收益；本轮只保留方案，不启动训练。
- **向 wkq 提出定向 10k 需求，先获取候选池可行性和统计反馈。** 推荐原 5k 不变、追加约 3,500 张广泛采样 + 1,500 张补缺采样。该方案同时改变规模与组成，应称“定向数据扩充”，不能当成纯数据量实验。
- 正式数据对照前单独固定初始化、学习率、增强、更新预算和相同 dev 评价点。只有与历史条件一致时才复用旧 S0 对照；若改学习率/初始化，须建立相应对照，不能把所有收益归给数据。
- batch2、20k updates 对 5k/10k 分别约为 8/4 次平均曝光；若同时把更新预算翻倍，就混入了额外计算。数据包准备不等于获准长训。
- lcy 接收新版仅核对新增/变更的输入及跨分区关系，旧子集和模型工程证据继续复用。10k 尚未构建/接收；wkq 本人尚未确认此需求。wyz 排序、公共评价和语言标注均不在本轮执行范围。
