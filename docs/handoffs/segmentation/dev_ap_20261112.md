## AP 与选择入口

- `segmentation.evaluate` 读取 trainer checkpoint，校验 SHA256、模型指纹、训练配置和数据来源，严格加载八类模型；直接调用固定官方 `forward/instance_inference`，top-100 query×class，FP32，无语言阈值过滤。
- `segmentation.evaluation` 调用 pycocotools COCOeval，mask IoU 0.50–0.95 / maxDets=100，输出百分数 AP/AP50/AP75/大小目标/逐类；无正例记 null。AP 的 100 条输出允许同一 query 对应多个类别，不能直接作为语言候选。
- 独立 `select_checkpoint` 消费同一配置/数据/训练与评价源码下的完整 dev 报告，复核报告、预测和 checkpoint hash。最大 mask AP、同分最早 update；不复制权重，只发布引用型 `selection.json`。
- 未接训练循环内周期 hook；现有保存点可接独立评估，再按原训练源码恢复。训练状态不受评估干扰。
- 正式路径拒绝 train/test、训练 ID/hash/source ID/group 重叠、pilot checkpoint、不完整结果与无效 AP。正式 dev 模板未填 hash 时拒绝执行。冻结证据/官方来源边界/全量近重复审查仍由 wkq 发布，hash 本身不证明这些条件已满足。
- 训练 pilot 诊断始终 `selection_eligible=false`，不产生正式选择结果。没有实现或复制 wkq 的语言关联/评价规则；其最新 `evaluation.metrics` 与本分割 COCO AP 的职责和指标单位分别记录。
