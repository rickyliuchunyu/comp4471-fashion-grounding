## 1. 规模、选图顺序与现有依据

1. **先报可行性，再构建。** 返回符合来源与分区约束的候选图片/独立组数、各目标可用量、冲突/无效/缺文件排除量、预计新增磁盘量。区分“只有源metadata筛选”和“已下载、做像素/近重复筛选”，不能把前者报成可发布量。复用已有源索引、hash和采集脚本；旧6500候选的筛选报告不代表整个官方剩余池已去重。
2. **第一阶段：10k＋约5k，目标15k。** 建议新增约2500广泛＋2500定向；先统计广泛部分已经覆盖的弱组，再补缺。固定seed（沿用2026），记录实际配额与选择规则。比例是可协商采集建议，不是已证明最优配方。
3. **第二阶段：累计新增约10k，目标20k。** 根据第一阶段剩余池的独立组和弱项缺口决定，不机械把每项配额翻倍。若先发布15k，之后20k必须保留整个已发布15k为严格子集，另列第二次增量；始终可追溯回原10k。
4. 实际可用不足时发布真实规模与缺口，不跨组拆分、不复制/翻转/裁剪凑新图片。每个新增近重复组最多取一个代表，且不与旧10k共享组。旧10k本身10000图/9976组的历史结构保留；达到15k/20k时，组数预期分别是14976/19976，而非声称全部图片独立。

## 2. 首批新增5k的采集软目标

small指**原图源mask面积≤1024像素**，extreme≤256，另报告相对面积，不用缩图或裁剪制造小目标。表中均按新增去重图片计；一图可命中多行，不能求和当总图数。先反馈可用量再确定配额；未达软目标只记缺口，不绕过隔离和有效性硬条件。

| 优先项 | 首批新增5k建议量 | 优先变化及限制 |
| --- | ---: | --- |
| 小袜 sock | ≥200图 | 裤脚/鞋邻接、不同遮挡、肤色/背景；保留源实例粒度 |
| 小腰带 belt | ≥300图 | 细长、与衣物低对比、仅部分可见；不补画不可见区域 |
| 小头饰 headband/head covering/hair accessory | ≥200图 | 发色、形态、视角；保留聚合源类名称，不冒称全部为发夹 |
| 小手表 watch | ≥150图 | 小表盘/细表带、手臂背景、不同朝向 |
| 小鞋 shoe | ≥700图 | 款式与背景多样；细带、镂空、遮挡鞋优先，保留双鞋原有实例关系 |
| 包 bag, wallet（全部尺寸） | ≥400图 | 细肩带、遮挡、多个可见片段；维持整体款式覆盖 |
| 其中小包 | ≥50图 | 是包行的子集；不围绕dev仅2个小包挑近似样本 |
| 极小目标（上述细类优先） | ≥300图 | 是small子集，另报实例数及每细类命中 |
| 有证据的复杂边界 | ≥300图 | 与上述各行可重叠；见下一节的证据口径 |

广泛部分继续覆盖top/pants/skirt/outerwear/dress及容易/中等场景；不把新包变成只有困难配饰的集合。报告旧10k、第一增量、第二增量（若有）、合并包四种视图的八类/26源细类图片、组、实例与尺寸分布；没有第二增量就不填虚构值。

## 3. 复杂边界如何选、如何记

采样目标包括细长结构、鞋的镂空、包带、遮挡后不连通但属于同一源实例的可见区域，以及与背景相近的真实边界。不能仅凭“shoe/bag/belt”类别推断某张图符合这些语义。

- 可用源属性或mask几何（细长、多个连通分量、孔洞等）**筛选线索**，保留规则/阈值/代码版本；几何线索不能自动升级成“遮挡”“镂空鞋”或“边界正确”。
- sidecar区分 `source_attribute`、`mask_geometry_proxy`、`visual_observation`、`unknown` 等依据，至少保存image ID、source annotation ID、目标标签、证据位置和检查者类型/日期。由Codex看图就记AI观察，不写human confirmed；人工确认需要真实检查者和处置记录。
- “有证据的复杂边界”命中需有对应源标注支持或明确看图记录；单纯启发式命中单列为proxy，不混入确认计数。未确认的困难语义可保持unknown，不影响来源/几何合法图片作为广泛样本使用。
- 不改写官方mask、不闭合空洞、不膨胀/平滑边界、不合并双鞋或拆分同一实例的分离分量。轮廓疑似错误单列问题；困难但合法样本保留，无效样本按原转换规则隔离并记录。

新增视觉检查聚焦上面改变的采样范围：复用旧八类图示，不重看旧10k。对新增源细类/边界标签按固定seed分层抽查，数量与不足项写清；需要声称人工完成时由实际人员确认。技术接收与三方正式冻结分开，不代签人工复核。
