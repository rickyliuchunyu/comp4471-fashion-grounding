# 50k 分割工作台（历史版本）

本页记录旧版 50k 的启动与验证。新版 GUI 和下游候选的权重、目录及运行方式见[当前候选交接](current_candidates.md)。

macOS 双击[打开分割工作台.command](../../../scripts/segmentation_gui/打开分割工作台.command)即可浏览。工作台在本机 127.0.0.1:8765 提供网页，打开时默认显示开发集第 1 张。左侧为原图，右侧为分割叠加，可切换图片、设置最低分数、查看边框或单独查看某个 decoder query。

**开发集**读取[已交付的 50k＋0.3 候选包](u50000_candidates_dev250_20261118.md)。250 张图及关联的候选和掩膜位于本机 `outputs/segmentation_gui/dev250/`，可离线浏览。页面显示的分数是候选分数，滑条范围从交付阈值 0.30 起。

**我的图片**支持 JPG、PNG 和 WebP。选择文件后可预览，点击「开始分割」才经 SSH 发送到项目服务器。服务端加载固定的 50k 权重，以 CPU 执行相同的候选解码器。大图按比例缩放到长边最多 1,440 像素，返回框和掩膜均对应页面显示的处理尺寸。原图像素和返回结果在内存处理。CPU 推理需要服务器在线，一次处理一张。

## 本次界面验证

使用开发图 1000008811 走了一次实际文件上传。四个实例的类别、query ID 和框均与缓存一致。三个 mask 逐像素一致，裤子的 mask 相差 1 像素，IoU 为 0.99997。浏览器验证覆盖切图、实例筛选、分数过滤、边框开关及窄屏布局。

## 在另一台已获服务器访问权的 Mac 上准备

- 将交付清单 `selected_entry` 所在目录中的 `candidates_predicted.json`、`image_manifest.json`、`images/`、`masks/` 复制到本机 `outputs/segmentation_gui/dev250/`。GUI 会核对固定版本。
- 本机 `.venv-segmentation/bin/python` 需要 Pillow 和 pycocotools。按本机 SSH 配置创建 `outputs/segmentation_gui/ssh.json`，例如 `{"ssh":["ssh","-o","BatchMode=yes","your-project-host"],"root":"/root/autodl-tmp/fashion-grounding"}`。SSH 目标需要能读取已部署的分割代码、环境、上游源码和 50k 权重。
- 也可在项目根目录运行 `.venv-segmentation/bin/python scripts/segmentation_gui/serve.py --open`。本地入口仅监听回环地址。
