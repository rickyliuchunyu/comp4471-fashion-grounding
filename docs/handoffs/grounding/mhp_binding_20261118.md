# MHP v2 同图方位与颜色训练对照

采用 wkh 的 b82fc99 数据交接。合并训练包 1655 图，其中 1587 图有查询，共 5604 条弱标签。Fashionpedia 原 M2 的训练集有 1235 图。新训练和旧实验相同种子42、batch32、490步、冻结 SigLIP 2。各检查点使用原先 642 条人工通过的 Fashionpedia GT dev 总体指标选择。所有推理关掉方位规则。固定划分的 ID、内容哈希、组 ID 清单两两互斥。最终测试只检查清单。

M2-mixed-CE 沿用均匀采样和普通交叉熵，可与 M2-FP 看同预算的数据变化。两种 paired 方法使用完全相同的顺序，每批16条来自新增 MHP，其中8条来自两组方位对，8条来自两组颜色对，其余16条来自父包。均用 CE 加同图目标间隔损失。M2-binding-pair 的文本系数直接加权几何和候选 mask 内的 12 维颜色直方图。与 M2-mixed-pair 的差异包含空间交互结构与颜色输入，未单独分离两者。

## 独立 MHP dev 草稿诊断

200 张图，1036 条 AI 初标。方向200组、颜色59组，每组两个目标与中英文共四条查询。严格标准按类别和一对一实例关联，掩码达标另按 IoU ≥ 0.5。同一个图可能同时提供颜色对与方位对。GT 使用官方实例候选，50k 使用 lcy 固定权重导出的候选。

| 方法 | GT 方位四条全对 /200 | GT 颜色四条全对 /59 | 50k 方位四条全对 /200 | 50k 颜色四条全对 /59 | 50k 两件都检出时方位 /130 | 50k 两件都检出时颜色 /42 |
|---|---:|---:|---:|---:|---:|---:|
| M2-FP | 0 | 20 | 0 | 11 | 0 | 11 |
| M2-mixed-CE | 0 | 20 | 0 | 9 | 0 | 9 |
| M2-mixed-pair | 0 | 16 | 0 | 7 | 0 | 7 |
| M2-binding-pair | 0 | 25 | 0 | 12 | 0 | 12 |

端到端方位对中，按冻结匹配能同时召回两件的有130组，颜色对有42组。这些是严格双目标指标在该候选下的覆盖上限。所有模型即使给定 GT 也仍无一张方位图达到四条全对。原模型到新版，GT 方位单条由296/800升至383/800，GT 颜色由178/236升至194/236。

另作基于已归档分数的对照，事后只比较两个带正确标签的官方目标分数。方位同一语言的两个目标都排对，从9/400到38/400，四条全对仍为0/200。说明其他候选竞争无法单独解释结果；这项诊断需要已知答案作为候选过滤，只用于定位问题。
