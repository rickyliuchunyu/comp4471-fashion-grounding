# 同图双目标训练损失对照

采用已发布 1235 图训练包、固定种子42、batch32、490步。三组使用完全一致的数据顺序。每批一半查询来自86张已标注的同图不同目标配对，全程复用冻结的图文特征。标准 M2 使用全部候选上的交叉熵。两个试验在保留交叉熵的同时，加权重2、间隔1的软间隔损失，要求每条查询的正确目标分数超过同图反向描述所对应的目标。一个版本约束最终分，另一个版本单独约束空间分支。正负标签只从发布的训练配对组读取，推理时不用方位规则。

单条得分有小幅波动，整图指标无改善。最终分版本在训练配对与草稿非鞋子组退步。几何版本在训练配对上与基线持平。保持原 M2 为当前参考模型。草稿统计为排序与机器初标吻合的计数，官方实例候选不含分割误差。主 dev 的最佳检查点仍以 GT 总体选对率选出。实验不含颜色配对训练。

训练数据分布按英文侧每组只计一次，用颜色词表匹配及标注标签统计。颜色词出现于958张图，其中196张的相关查询有同项目类别竞争，169张有同源细类竞争。方位或外观加方位涉及302张图，其中273张有同项目类别竞争，267张有同源细类竞争。颜色或方位合并去重后，有同源细类竞争的共有293张图。这些统计代理不保证颜色或方位词确实决定答案，明确归组的反向训练对为86张。
