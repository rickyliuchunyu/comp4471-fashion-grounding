# 课程要求与交付

来源：[COMP 4471 / ELEC 4240 课程项目页面](https://course.cse.ust.hk/comp4471/project.html)。以下为 2026 年 10 月 3 日读取的要求整理，提交前再检查课程页面与 Canvas 通知。时间均为香港时间。

## 提交内容

| 项目 | 截止 | 格式与内容 |
| --- | --- | --- |
| Proposal | 2026-10-05 23:59 | 一个段落，200–400 词；说明问题、背景阅读、数据、拟用方法和评估 |
| Milestone | 2026-11-06 23:59 | 课程指定模板，2–3 页；说明已做工作、初步结果和后续计划 |
| Final report | 2026-12-05 23:59 | 课程指定模板，6–8 页 PDF；摘要不超过 300 词，完整说明方法、实验与结论 |

[课程提供的 Overleaf 模板链接](https://www.overleaf.com/latex/templates/cvpr2022-official-latex-template/bphmxkmtqzjh) 必须以课程当前指引为准，模板页面标题可能与 URL 中的年份不同。

团队最多三人，报告列出全体成员，由一人提交 Canvas。课程外协作者不允许；本项目不同时用于其他课程。基础代码和公开实现需要在报告正文中引用。先用公开架构是允许的应用方向，实验深度和论证仍由团队完成。

课程报告默认公开；若不希望公开，需至少提前一周通知教师。GitHub 的公开或私有设置与课程报告是否公开是两个独立设置。

补充材料单独提交；不包含模型权重、整个深度学习框架的源代码或超过 10 MB 的代码。GitHub 工作仓库与 Canvas 提交包按各自用途整理，不能把整个数据和模型目录作为补充材料上传。

## 评分关注点与项目对应证据

| 报告部分 | 比重 | 本项目应提供的证据 |
| --- | --- | --- |
| Introduction | 10% | 任务、实际用途、同类多实例选择的困难、研究问题 |
| Related work | 10% | 服饰数据、实例分割、区域文本匹配相关工作与引用 |
| Data | 10% | 八类映射、统计、划分、查询标注和人工复核 |
| Methods | 30% | 分割与匹配流程、训练方式、规则与学习方法、空间融合 |
| Experiments | 30% | 公平对照、消融、端到端指标、延迟和失败案例 |
| Conclusion | 5% | 结论、局限和后续方向，有结果支持 |
| Writing | 5% | 结构、图表、格式和引用清楚完整 |

课程没有指定必须达到的服饰分割 AP、语言选择准确率或毫秒级速度。因此以明确问题、公平实验和诚实分析作为项目推进标准；不把任何旧业务目标写成课程规定。
