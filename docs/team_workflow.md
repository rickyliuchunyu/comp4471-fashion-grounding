## 接口与存储

框统一原图像素 xyxy、右下排他；项目类别为 1–8，框架训练 ID 为 0–7，转换显式记录。图文特征维度 D 从 SigLIP 2 checkpoint 验证；几何为 12 维，不沿用旧 DINO/BGE 的维度。候选序列、缓存和失败语义见 [实现规范](implementation_spec.md)。

GitHub 保存源码、配置、说明、小型指标和证据索引。原始图片、处理数据、权重与大缓存进入团队确定的共享存储，目前尚未确定位置。下载来源、使用条件、revision/hash 与数据 manifest 必须记录。

## 算力与启动检查

先按一张 24GB GPU 规划，具体平台、预算和可用环境待确认；不预先承诺训练时长。Mask2Former、冻结特征提取与 E1 可以分进程/环境运行，不要求所有模型常驻。

1. 确认官方数据与权重可访问，SAM 3 若无法使用，在开发阶段登记 E1 替代系统。
2. 固定各进程 Python/PyTorch/CUDA、基础仓库与 processor 版本；共享格式连接环境。
3. 检查真实图片与 mask 解码、坐标、类别和 GT 裁剪。
4. 跑通 B0/B1/B2、分割小批量训练和 checkpoint 恢复。
5. 检查 M1/M2 梯度、实际参数量、显存与耗时。
6. 根据实测确定正式预算，按 [实验时间表](experiment_plan.md) 执行。

## 实验登记

[registry.csv](../experiments/registry.csv) 的 S0/B0–B2/M1–M2/E1/D1–D2/X1–X5 是计划系列。执行时追加唯一行，例如 M2-oracle-seed42，保留计划行；旧 S/L 编号在 [归档表](../experiments/archive/registry_20261004.csv)，不作为已运行结果。

开始前填负责人、代码 commit、完整配置、manifest hash、seed、初始化权重与 run_dir；结束后填真实指标与状态，失败也保留。mask AP 与选择 accuracy/IoU 不混用，附完整 metrics 文件；空白不是零。复核由另一成员核对配置与证据。
