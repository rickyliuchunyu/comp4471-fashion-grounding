# 实验设计与评估规则

版本 `2026-11-05`。所有实验仍为计划，无已运行结果。参数见 [training_plan.json](../configs/training_plan.json)，数据见 [协议](data_protocol.md)。实验系列在 [registry.csv](../experiments/registry.csv) 登记，旧编号保留于 [历史表](../experiments/archive/registry_20261004.csv)。

## 1. 问题与核心实验

研究现成图文表示能做什么、少量领域监督是否有用、空间学习是否优于规则，并分解候选漏检与排序错误。所有改进都是假设，不预填指标。

| ID | 方法 | 对照目的 | 训练 |
| --- | --- | --- | --- |
| S0 | Fashionpedia 八类 Mask2Former-R50 | 固定候选提供者 | 微调分割器 |
| B0 | 类别与位置规则 | 可解释启发式基线 | 无 |
| B1 | 冻结 SigLIP 2 区域文本相似度 | 预训练零样本能力 | 无 |
| B2 | B1 + 简单方位规则 | 显式空间信息的强基线 | 无网络训练，dev 选规则权重 |
| M1 | SigLIP 2 + 外观残差排序 | 少量领域监督的作用 | 仅小网络 |
| M2 | M1 + 文本条件空间模块 | 额外空间学习的作用 | 仅小网络 |
| E1 | SAM 3，或预先登记替代 Grounding DINO + SAM 2 | 完整系统对照 | 核心只推理 |
| D1 | 左右反事实配对 | 是否随正确空间描述选择不同目标 | 复用 B0–M2 的预测 |
| D2 | 人工自然改写组 | 是否依赖模板或固定词序 | 复用 B0–M2 的预测 |

B0–M2 都在同一组 GT 候选和同一组固定预测候选上评价。M2-M1 是空间分支的控制消融；M1-B1 检查领域适配；M2-B2 检查复杂学习是否值得。不要只与不支持外观的 B0 比较。

E1 使用自己的输出，仅放入端到端比较表；不同预训练数据、参数量和候选生成方式是系统差异，不能解释成单模块消融。检查可获得的预训练来源，无法确认测试图片是否曾进入基础模型预训练时如实说明，不声称严格未见图像的零样本实验。

## 2. 固定条件与选择规则

每个运行记录 commit、resolved config、数据/查询 manifest SHA256、映射版本、预训练 URL/revision/hash、环境、seed 和唯一 run ID。运行输出不得覆盖，失败也登记。

只在 dev 选 checkpoint、候选阈值、规则词表/权重和 E1 提示方式。默认 S0 用 dev mask AP；M1/M2 用 oracle dev selection accuracy、patience 5。采用预测候选适配时，对两方法使用同一额外预算和同一 checkpoint 选择规则并提前登记。B2 权重候选为 [0,1,2,5,10]，不在测试集搜索。

B0–M2 固定 S0 权重、解码器、候选序列与图像输入。M1/M2 固定训练集、采样、外观结构、optimizer、最大 epochs 和早停。M2 只新增空间分支。模型不读取 query type、人工目标类别或 target ID。规则只解析实际查询字符串。

E1 在开发阶段选择一种系统及其固定 checkpoint：首选 SAM 3；访问/环境不适用时登记替代 Grounding DINO + SAM 2。输入完整查询，返回最高置信度的非空 mask，分数并列按稳定输出索引；无输出保留失败。禁止 GT 框/点提示和从多个输出中挑最高 GT IoU。原生中文与固定翻译流程如同时运行，应单独列行并计翻译时间。仅英文时，与内部方法的同一英文查询子集比较；不能使用不同的测试集合声称整体优劣。

## 3. 可选实验与停止条件

| ID | 对照 | 控制与优先级 |
| --- | --- | --- |
| X1 | DINOv2 + BGE-M3 + 训练投影 vs 当前图文起点 | 相同数据/候选/训练预算；编码器差异单独注明，必要时配对空间设置 |
| X2 | 25% / 50% / 100% 语言训练数据 | 图片级嵌套子集，翻译不跨子集；固定评价与训练预算上限 |
| X3 | 普通区域裁剪 vs mask 外背景抑制 | 同模型、裁剪、mask 来源与训练预算 |
| X4 | 英文 Marqo-FashionSigLIP vs SigLIP 2 | 同一英文查询、同候选与区域输入，注明预训练差异 |
| X5 | FP-only vs FP+DF2 的共有五类分割 | 相同五类头、初始化、batch、updates、augmentation；混合比例先定 1:1 |

按 X1→X2→X3→X4→X5 的优先顺序选择，不承诺全部完成。X5 需要另行完成一致的五类前景定义与评估检查，其他类别不参与该任务的前景监督或 AP；不能用八类 S0 对比不同头后把全部差异归因于混合数据。两源各报五类 AP；未标的鞋、包、配饰不能记为 DF2 八类零分。当前不开展八类 partial-label loss 实验。

若时间不足，先删除扩展，再统一缩小主实验预算；仍需保留 B1/B2、M1/M2、端到端评价和失败分析，不能只展示成功案例。数据量与预算变化在 final test 前冻结。

## 4. 分割与候选质量

S0 使用标准 COCO mask AP，IoU 0.50–0.95、步长 0.05，maxDets=100，报告 AP50/AP75、AP-small 和逐类结果。没有正例的类别按 evaluator 输出 N/A，不手填零。语言候选解码与标准 AP 解码分开，见 [技术设计](technical_design.md)。

另报两个不同覆盖指标，避免混淆：

- **Geometric recall@0.5：**该查询目标与至少一个候选的 mask IoU ≥ 0.5，不要求类别一致，用于观察几何候选上限。
- **Matched candidate coverage：**下文一对一同类关联中存在目标 ID 的查询比例，与 predicted selection accuracy 配套。

二者不同是允许的，例如预测类别错误但 mask 重叠。不能将其中一个与另一个定义的条件准确率相乘。

## 5. 一对一关联与核心指标

关联只供评估器：预测按分割分数降序、同分按 candidate ID 排序；对每个预测，在未占用且同类别的非 crowd GT 中选 mask IoU 最大者，若 IoU≥0.5 则关联；GT 同 IoU 按 annotation ID。重复预测不能都对应同一个 GT。全部内部方法复用该关联，它不是训练 matcher，也不替代 COCO evaluator。

| 指标 | 定义 |
| --- | --- |
| Oracle selection accuracy | 选中 GT annotation ID 等于目标 ID 的查询比例 |
| Predicted selection accuracy | 选中候选经上述关联对应目标 ID 的查询比例 |
| Conditional selection accuracy | 仅在存在关联目标候选的查询中计算 predicted accuracy |
| Mean target-mask IoU | 全部查询的最终输出 mask 与目标 mask 的 IoU 平均 |
| Success@0.5 | 全部查询中最终 mask IoU≥0.5 的比例 |
| Macro category accuracy | 有样本类别 accuracy 的等权平均 |

无候选、无输出、拒绝、空 mask 或推理失败都保留在分母，IoU=0。选错实例仍计算实际 mask IoU，不按标签人为置零。几何成功与类别约束的选择准确率不等价。

在固定关联定义下：predicted accuracy = matched coverage × conditional accuracy；coverage=0 时 conditional 为 N/A。E1 主要报告目标 IoU/Success，不强行按内部八类关联输出同名选择准确率。

## 6. 分组、诊断与统计

按语言、类别、源细类、query type、候选数量、同类数量、源细类同类数量、面积和困难子集报告。query type 可多标签，分组数量不可直接相加当总量。单独检查鞋子、宽泛 accessory、自然改写和人工独立测试描述，避免总体分数被容易样本主导。

D1 对每对有效左右查询报告“两条都正确”的比例，不只检查输出是否改变。D2 报告改写组每条准确率与整组全部正确率；中英同义配对另报一致率与两条均正确率，一起选错不是理解成功。预先冻结组定义与目标，不根据模型输出挑选测试难例。

M1/M2 跑 seeds 42/43/44，报告每 seed 及 mean/std。预登记 seed 42 的方法差值按图片做 paired bootstrap 1,000 次，seed 42，报告 95% 区间；该区间只反映测试图片采样不确定性，不替代训练种子变化。一次抽样带回同图全部语言、改写与反事实记录。子组同时注明图片数和查询数。

## 7. 计时与复现

记录 GPU/软件、输入尺寸、候选数、文本长度、预热与精度。建议预热 20 次、测量 100 次作为微基准，并在真实测试图分布单列计时；GPU 起止同步，报告 mean/p50/p95 与 peak memory。

首次图片处理包括分割、区域编码、文本编码、排序与必要的模型重载；同图新查询只复用固定图片候选和冻结区域特征；模型冷启动单列。离线缓存不能冒充首次推理。纯计算与上传/解码/叠图的演示 wall time 分开；外部翻译或远程调用另计。B0–M2 的基础候选缓存一致，E1 单独说明其缓存能力。

最终至少产出：分割/候选质量表、共享候选排序表、包括 E1 的端到端表、延迟与显存表，以及漏检、边界、同类选错、外观/空间失配、双语不一致等失败案例。未运行格子为空或 N/A，不填目标数字。
