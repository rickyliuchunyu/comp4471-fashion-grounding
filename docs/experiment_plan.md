# 八类分割和自然语言实例选择实验计划

本计划把课程任务分为分割和目标选择两部分。所有实验目前均未运行，具体数据量、训练步数和批大小在新环境的小规模检查后确定。

## 数据和划分

从官方来源获取 DeepFashion2 和 Fashionpedia。为八类标签建立明确映射并记录被排除的类别、图片和原因；不能把服饰部件标注当作整件服饰实例。保留源图片 ID、实例 ID、数据集来源和映射版本，导出处理前后的图片及类别统计。

保持官方训练和验证边界。若使用官方已标注验证数据建立最终测试集，先按图片划出开发验证与最终测试子集，并冻结清单和哈希。能追踪到的同商品、同人物或近重复图片进一步按组隔离。最终测试图像、描述及改写均不用于训练、阈值选择或方案选择。

## 查询数据

每条记录包含图片 ID、完整查询、语言、目标实例 ID、查询类型和人工复核状态。首阶段只处理单目标且明确的中英文描述，支持类别与空间信息；视觉属性描述由人工确认。中英文分别评估，以图片左、右为统一空间参照，明确记录规则。

同一类别存在多个实例的查询单独报告，避免只在一张图唯一的某类别上验证。左右位置、外观与类别必须确实指向目标；不能凭自动模板虚构颜色、图案或材质。模糊或多解描述进入复核列表，不悄悄改为容易的测试样本。标注覆盖八类，并报告各查询类型、类别、图片和实例的实际数量。

## 分割实验

| 实验 | 改变的因素 | 比较方式 |
| --- | --- | --- |
| S1 | 单数据源和混合数据源训练 | 相同架构、公开初始化和约定的训练预算；在相同测试图片上比较 |
| S2 | 混合数据的源采样权重 | 改变采样策略，保持其余训练设置一致 |
| S3 | 推理精度或输入分辨率 | 固定权重、图片、阈值与候选数，一次改变一个因素 |

两套数据集分别报告指标。单源训练没有监督覆盖的类别必须标记出来，避免把新类别覆盖变化误写成所有类别都改善。主指标为 COCO mask AP，另报 AP50、AP75、AP-small 和八类 AP；展示小物件遗漏、类别混淆及跨数据集性能变化。

## 语言选择实验

| 实验 | 方法 | 目的 |
| --- | --- | --- |
| L1 | 类别和位置规则 | 建立可解释基线 |
| L2 | 学习后的区域文本对齐或排序 | 检查视觉语言学习的贡献 |
| L3 | L2 加显式空间特征 | 检查同类多实例和方位描述的改善 |

候选视觉特征可以由冻结的 DINOv2 提取，完整查询由冻结的 BGE-M3 编码。文本和视觉特征需要训练映射到相同空间。所有学习参数、几何特征和匹配规则在配置中明确记录，不能把规则带来的增益全部归于语言模型。

训练时可使用真实实例掩膜建立正例与同图负例；最终必须在预测候选上评估。真实掩膜候选的实验用于诊断目标选择能力，不能替代端到端结果。

## 评估规则

1. 目标选择准确率：在真实掩膜候选诊断中，选中的实例 ID 是否等于目标 ID。在预测候选中，评估器先按固定的一对一、同类别、掩膜 IoU ≥ 0.5 规则匹配预测与标注，再判断所选候选是否对应指定目标。匹配冲突的处理必须固定并记录；推理过程不读取真实标签。
2. 最终 Mask IoU：直接计算所选预测掩膜与指定目标真实掩膜的交并比，再对全部查询求平均。无候选、空掩膜或推理失败按零计；选错实例时仍记录实际交并比，通常接近零，不凭评估标签重写非零值。该指标同时受目标选择与轮廓质量影响。
3. Success at IoU 0.5：报告最终目标掩膜 IoU ≥ 0.5 的查询比例。这是单目标查询的成功率，不能与检测器的 COCO AP 混用。
4. 分组结果：类别、方位、视觉属性、同类多实例和语言分别统计。
5. 延迟：分别记录分割、候选编码和查询匹配时间，并报告首次图片处理与图片特征缓存后的查询响应。冷启动和预热后的平均值及 p95 分开。

在同一最终测试集合上比较所有保留方案。查询来自同一图片而相互相关，若计算置信区间，按图片而非按独立查询重采样。样本数量在数据审查后确定，不将规划数量写成已完成数量。
