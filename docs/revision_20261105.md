## 与 proposal 的关系

[已提交正文](proposal_submitted.md) 来自用户提供的 PDF。它明确采用 Fashionpedia 八类主任务，并将 DeepFashion2 单源/混合比较限定在五个共有类别。它没有要求实现早期草稿中的八类 source-aware partial-label loss。保留提交版正文，不用新方案改写历史承诺；后续报告解释调整理由与实际完成范围。

| 项目 | 当前决定 | 理由 |
| --- | --- | --- |
| 单张图片、单目标整件服饰、中英文查询 | 保留 | 问题明确且与 proposal 连续 |
| Fashionpedia 与八类映射 | 保留 | 有实例 mask、细类和属性；查询需另行标注 |
| Mask2Former-R50 | 保留 | 作为可微调候选分割器，便于误差分解 |

| PRD 指定模型、延迟/QPS与验收数字 | 不继承 | 本项目研究问题与课程实验独立 |

## 来源与判断边界

- [Mask2Former](https://github.com/facebookresearch/Mask2Former)：公开分割实现，仓库已归档；环境需实测。
- [SigLIP 2 论文](https://arxiv.org/abs/2502.14786) 与 [模型](https://huggingface.co/google/siglip2-base-patch16-224)：图文联合、多语言训练；在本项目上更有效仍是假设。
- [Fashionpedia](https://github.com/cvdfoundation/fashionpedia) 与 [DeepFashion2](https://github.com/switchablenorms/DeepFashion2)：监督范围与原始标注。
- [DINOv2](https://github.com/facebookresearch/dinov2) 与 [BGE-M3](https://huggingface.co/BAAI/bge-m3)：原方案编码器，各自预训练不等于联合对齐。
- [SAM 3](https://github.com/facebookresearch/sam3) 与 [Grounded SAM 2](https://github.com/IDEA-Research/Grounded-SAM-2)：外部系统候选，须检查访问、环境和确切 checkpoint。
- [Marqo-FashionSigLIP](https://huggingface.co/Marqo/marqo-fashionSigLIP)：可选英文服饰表示对照，不承诺中文能力。
- [RefCOCO 系列](https://github.com/lichengunc/refer)、[LAVT](https://arxiv.org/abs/2112.02244)：通用指代表达与端到端分割背景，不加入核心训练依赖。
