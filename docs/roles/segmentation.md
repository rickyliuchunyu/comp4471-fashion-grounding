## 目标与边界

交付可复现的 Fashionpedia 八类 Mask2Former-R50，以及供所有内部语言方法共用的固定候选。负责初始服务器核查和最小 pipeline 接通；不替 A 改写排序方法，不替 B 修改评价规则。无需等待完整语言查询集才开始分割工作。

## 第一批工作：环境和合法候选

1. 检查旧镜像实际 conda 环境、GPU/驱动、PyTorch/torchvision、Detectron2、CUDA Toolkit 和自定义算子；保存环境记录，不先重装。
2. 锁定基础实现 commit 和公开实例分割 checkpoint，记录 URL/revision/hash。适配八类分类头，核查加载时仅有预期的分类头形状变化。
3. 接收 B 的合法转换小样本，核对 RGB、尺寸、类别 ID、mask、框和 crowd 策略。
4. 实现独立的训练/推理/候选导出入口；明确标准 COCO AP 推理与语言候选解码的差异。
5. 完成一次前向与反向、合法候选导出和 checkpoint 保存/恢复；有授权的 GPU 预算后再做短训练检查。

验收：环境能重建；输出框和 mask 对齐原图；候选 ID/顺序稳定；无候选/空 mask 处理明确；恢复点能恢复模型、优化器、调度器、混合精度状态和训练进度。运行时间与显存填写实测值。

## 第二批工作：S0 与固定候选

- 使用 B 发布的冻结 train/dev 数据包，按运行配置微调；只在 dev 选择 checkpoint 与候选阈值。
- 起始预算、输入尺寸与 batch 以现有规划为起点，小规模验证后记录调整；没有运行前不承诺训练耗时。
- 报告 mask AP/AP50/AP75、逐类和小目标结果，输出全量候选供统一评价器检查覆盖率。
- B0/B1/B2/M1/M2 使用相同候选包，不因某个语言方法表现较差私自重新过滤候选。
- 最终测试预测只在全组锁定方案后生成/评价；失败样本保留。

验收：权重、完整配置、源码/标注哈希、日志、AP 结果和候选 manifest 齐全；A 可从候选文件独立裁剪，B 可读入评价器。

- 可选 X3 提供普通框、同框 mask 外填色、扩框上下文三个明确输入条件；A/B 保持其他条件一致。
